# S0-T01 — Baseline audit và Tauri runtime proof

Ngày audit: 2026-08-30

Môi trường audit: Linux container (không phải Windows, không có desktop display)

## Stack xác nhận từ repository

| Thành phần | Bằng chứng |
| --- | --- |
| Frontend | React + Vite trong `package.json`, entrypoint `src/main.jsx` |
| Desktop | Tauri 2 trong `src-tauri/Cargo.toml` và `src-tauri/tauri.conf.json` |
| Backend | Rust 2021 trong `src-tauri/Cargo.toml` |
| Lưu media hiện tại | File hệ thống + `media-index.json` trong app data; chưa có SQLite |
| Target sản phẩm | Cửa sổ desktop, cấu hình bundle trong `src-tauri/tauri.conf.json` |

Không có OmniRoute, scheduler, Facebook API hay SQLite trong phạm vi baseline này.

- Node `v20.20.2`
- npm `11.4.2`

- cargo `1.89.0 (c24e10642 2025-06-23)`
- Tauri CLI: chưa xác định được; package chưa có trong `node_modules` và registry bị proxy trả HTTP 403.

## Lockfile

- `package-lock.json`: chưa có. Lệnh tạo lockfile bị npm registry trả HTTP 403.
- `src-tauri/Cargo.lock`: chưa có. Lệnh tạo lockfile bị crates.io trả HTTP 403.

Vì hai lockfile chưa tạo được, baseline cài đặt tái lập (`npm ci` và `cargo check --locked`) vẫn là blocker. Không tạo lockfile thủ công hoặc giả mạo integrity.

## Sửa lỗi baseline trong audit

1. Bỏ phụ thuộc runtime `@tauri-apps/api` chưa cài được và sử dụng API global chính thức của Tauri, bật bằng `app.withGlobalTauri`.
2. Sửa effect tải media để không cập nhật state đồng bộ và hủy cập nhật sau unmount.
3. Cố định mốc thời gian hiển thị trong state để render React là idempotent.

Các sửa đổi này làm frontend production build và lint PASS; không thêm tính năng nghiệp vụ.

## Checklist Windows bắt buộc để đóng S0-T01

Chạy tại thư mục repository trên Windows sau khi bảo đảm npm/crates.io truy cập được:

1. `npm install` để tạo `package-lock.json`, sau đó commit lockfile.
2. `npm ci`.
3. `npm run build` và `npm run lint`.
4. `cargo generate-lockfile --manifest-path src-tauri/Cargo.toml`, sau đó commit `src-tauri/Cargo.lock`.
5. `cargo fmt --manifest-path src-tauri/Cargo.toml -- --check`.
6. `cargo check --locked --manifest-path src-tauri/Cargo.toml`.
7. `npm run tauri:dev`; xác nhận một cửa sổ có title **FlowPost AI** mở độc lập, không dùng tab Chrome tại localhost.
8. Trong cửa sổ Tauri: mở **Tổng quan**, lần lượt chọn các mục điều hướng, rồi mở **Thư viện media**; xác nhận không crash.
9. Nhập một ảnh thử nghiệm; ghi lại tên và dung lượng hiển thị.
10. Đóng hoàn toàn ứng dụng và chạy lại `npm run tauri:dev`; xác nhận ảnh vẫn hiển thị.
11. Xóa ảnh, xác nhận card biến mất; đóng/mở lại lần nữa để xác nhận ảnh không quay lại.
12. Chạy `git status --short` và lưu log/screenshot làm bằng chứng.

Không đánh dấu AC5–AC7 là PASS chỉ dựa trên việc `http://localhost:1420` hiển thị trong trình duyệt.
